# velikvisual.online

Сайт VelikVisual: лендинг, магазин клиента и косметики, галерея конфигов.
Хостинг — GitHub Pages (репозиторий `welixx387/velikvisual`), домен `velikvisual.online` (DNS в Timeweb).

## Что где лежит

| Файл | Зачем |
|---|---|
| `assets/js/config.js` | **Настройки магазина**: реквизиты для перевода, Telegram, Discord |
| `assets/js/shop.js` | Список товаров и цены (`PRODUCTS`) |
| `api/cosmetics.json` | **Кто что купил** — это читает мод в игре |
| `admin.html` | Страница для выдачи покупок: velikvisual.online/admin.html |
| `configs/configs.json` | Конфиги в галерее на сайте |
| `CNAME` | Домен для GitHub Pages |

Любой файл можно поправить прямо на github.com: открыть файл → значок карандаша → «Commit changes». Через минуту сайт обновится.

## 1. Включить оплату

В `assets/js/config.js` впишите реквизиты и ссылку на Telegram:

```js
pay: {
  bank: "Т-Банк",
  card: "2200 0000 0000 0000",   // номер карты
  phone: "+7 900 000-00-00",     // телефон для СБП (можно только одно из двух)
  recipient: "Иван И.",
},
telegram: "https://t.me/ваш_ник",
```

Как проходит покупка:

1. Покупатель кладёт товары в корзину, вводит ник и нажимает «Оформить заказ».
2. Сайт показывает реквизиты, сумму и код заказа `VV-…`, который нужно написать в комментарии к переводу.
3. После перевода покупатель жмёт «Я оплатил — отправить чек»: текст заказа копируется, открывается ваш Telegram, и он присылает вам скриншот чека и текст заказа.
4. Вы находите перевод в банке (сумма и код в комментарии) и выдаёте покупку — см. шаг 2.

Если `pay` пустой, сайт покажет «Реквизиты пришлёт продавец в Telegram».

Необязательно: если указать `yoomoneyWallet`, вместо перевода по реквизитам кнопка будет вести на автоматическую оплату картой через ЮMoney.

## 2. Выдать косметику после оплаты

Проще всего через **velikvisual.online/admin.html**: вставьте текст заказа из Telegram → «Разобрать заказ» → «Добавить игроку» → «Скопировать JSON» → «Открыть файл на GitHub», заменить текст и нажать «Commit changes». Если покупатель взял клиент, отправьте ему файл мода в чат.

Или вручную: откройте `api/cosmetics.json` и добавьте ник покупателя:

```json
{
  "version": 1,
  "admins": ["Wel1xx"],
  "players": {
    "steve123": { "cape": "glass", "wings": "angel" },
    "alex_pro": { "halo": "light", "pet": "cube", "aura": "snow" }
  }
}
```

Ник пишется **маленькими буквами**. Мод проверяет файл раз в 5 минут, и косметика сама появляется у игрока. Её видят все, у кого стоит VelikVisual.

| Косметика | Ключ | Стили |
|---|---|---|
| Плащ | `cape` | `glass`, `night`, `theme` |
| Крылья | `wings` | `angel`, `demon`, `theme` |
| Нимб | `halo` | `light`, `theme` |
| Питомец | `pet` | `orb`, `cube`, `crystal` |
| Аура | `aura` | `sparks`, `snow`, `theme` |

Ники из `admins` получают всю косметику бесплатно.

## 3. Добавить конфиг в галерею

1. В игре: меню → «Конфиги» → у нужного конфига кнопка «Код».
2. Добавьте запись в `configs/configs.json`:

```json
{ "name": "Мой конфиг", "author": "Ник", "tags": ["PvP"], "desc": "Короткое описание", "code": "VV1:..." }
```
