# velikvisual.online

Сайт VelikVisual: лендинг, магазин клиента и косметики, галерея конфигов.
Хостинг — GitHub Pages (репозиторий `welixx387/velikvisual`), домен `velikvisual.online` (DNS в Timeweb).

## Что где лежит

| Файл | Зачем |
|---|---|
| `assets/js/config.js` | **Настройки магазина**: кошелёк ЮMoney, запасная карта, ссылки |
| `assets/js/products.js` | Товары, цены и что выдаётся за покупку |
| `api/cosmetics.json` | **Кто что купил** — это читает мод в игре |
| `api/orders.json` | Заказы, которые робот уже обработал |
| `.github/workflows/payments.yml`, `tools/payments.py` | Робот автооплаты |
| `tools/connect_yoomoney.py` | Подключение ЮMoney (запускается один раз) |
| `admin.html` | Последние заказы и ручная выдача: velikvisual.online/admin.html |
| `configs/configs.json` | Конфиги в галерее на сайте |
| `CNAME` | Домен для GitHub Pages |

Любой файл можно поправить прямо на github.com: открыть файл → значок карандаша → «Commit changes». Через минуту сайт обновится.

## 1. Автооплата (без вашего участия)

Как проходит покупка:

1. Покупатель кладёт товары в корзину, вводит ник и нажимает «Оформить заказ».
2. Открывается оплата ЮMoney — платить можно картой любого банка. В платёж зашит код заказа `vv1.<ник>.<товары>.<…>`.
3. Робот на GitHub каждые 5 минут читает входящие платежи кошелька, проверяет сумму и записывает покупку в `api/cosmetics.json`.
4. Сайт показывает покупателю «Готово», а косметика сама появляется в игре.

Обычно от оплаты до появления в игре проходит 5–15 минут. Деньги приходят на кошелёк ЮMoney, вывести их можно на любую карту (например, Сбер) в приложении ЮMoney.

**Подключение (один раз):**

1. Заведите кошелёк на [yoomoney.ru](https://yoomoney.ru) и в приложении привяжите карту для вывода денег.
2. Запустите на компьютере, где есть эта папка и вход в GitHub CLI (`gh`):

   ```
   python tools/connect_yoomoney.py
   ```

   Скрипт откроет страницу регистрации приложения в ЮMoney и подскажет, что вписать, затем попросит нажать «Разрешить». Он сам сохранит доступ в секрет репозитория `YOOMONEY_TOKEN`, впишет номер кошелька в `config.js` и опубликует сайт.

Доступ даётся только на просмотр истории платежей — тратить деньги с кошелька робот не может. Журнал робота: вкладка **Actions → Payments** в репозитории.

Если сумма платежа меньше цены заказа (больше чем на 6 % — это запас на комиссию ЮMoney), робот покупку не выдаёт, а сайт просит покупателя написать вам.

## 2. Запасной способ: перевод на карту

Пока `yoomoneyWallet` пустой, сайт показывает карту из `pay` и код заказа, который покупатель вставляет в комментарий к переводу. Чтобы выдать такую покупку, откройте **velikvisual.online/admin.html**, вставьте код из комментария → «Разобрать заказ» → «Добавить игроку» → «Скопировать JSON» → «Открыть файл на GitHub», замените текст и нажмите «Commit changes».

## 3. Товары и цены

`assets/js/products.js`. У каждого товара есть постоянный номер `n` — он зашит в код заказа. Номера существующих товаров **не меняйте**, новому товару давайте следующий свободный номер. Цену, название и описание менять можно свободно.

## 4. Выдать косметику вручную

Откройте `api/cosmetics.json` и добавьте ник покупателя:

```json
{
  "version": 1,
  "admins": ["Wel1xx"],
  "players": {
    "steve123": { "cape": "glass", "wings": "angel" },
    "alex_pro": { "halo": "light", "pet": "cube", "aura": "snow" }
  }
}
```

Ник пишется **маленькими буквами**. Мод проверяет файл раз в 5 минут, и косметика сама появляется у игрока. Её видят все, у кого стоит VelikVisual.

| Косметика | Ключ | Стили |
|---|---|---|
| Плащ | `cape` | `glass`, `night`, `theme` |
| Крылья | `wings` | `angel`, `demon`, `theme` |
| Нимб | `halo` | `light`, `theme` |
| Питомец | `pet` | `orb`, `cube`, `crystal` |
| Аура | `aura` | `sparks`, `snow`, `theme` |

Ники из `admins` получают всю косметику бесплатно.

## 5. Добавить конфиг в галерею

1. В игре: меню → «Конфиги» → у нужного конфига кнопка «Код».
2. Добавьте запись в `configs/configs.json`:

```json
{ "name": "Мой конфиг", "author": "Ник", "tags": ["PvP"], "desc": "Короткое описание", "code": "VV1:..." }
```
